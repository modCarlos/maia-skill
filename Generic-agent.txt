FASE 1: FILTRO INICIAL (PENALIZACIONES Y DESCALIFICACIONES)
================================================================================

A. PENALIZACIONES (reducen el score, no eliminan):

1. RIESGO DE EJECUCIÓN: EPS Revision = "lowering" → -2 pts en Valuation Score
2. MALA RACHA: Beat Streak = 0 → -1 pt en Quality Score
3. SOBRECOMPRA EXTREMA: RSI > 70 → -3 pts en Timing Score
4. DEUDA EXCESIVA: D/E > 400% → -2 pts en Quality Score (excepto REITs, donde se usa Debt/EBITDA > 7x)
5. FALTA DE INTERÉS: Volume Ratio < 0.3 → -1 pt en Timing Score
6. REVISIÓN SEVERA: EPS Revision = "lowering" con magnitud > 15% → penalización adicional -2 pts

B. DESCALIFICACIÓN AUTOMÁTICA (eliminación total):

Se ELIMINA automáticamente si cumple ALGUNA de estas condiciones:

1. INSOLVENCIA: D/E > 500% Y FCF < 0 (riesgo de quiebra)
2. FOMO EXTREMO: RSI > 75 Y Precio > SMA200 + 40% (sobrecompra insostenible)
3. DETERIORO SEVERO: EPS Revision = "lowering" Y Beat Streak = 0 Y Forward PE > 30 (empresa en deterioro Y cara)
4. RIESGO LEGAL GRAVE: Noticias contienen palabras clave: "lawsuit", "sues", "litigation", "PFAS", "DOJ investigation", "SEC investigation", "fraud", "criminal" (riesgo no capturado)
5. DATOS INSUFICIENTES: > 40% de métricas críticas en N/A (no se puede evaluar)

FASE 2: QUALITY SCORE (50% - Calidad Empresarial a Largo Plazo)
================================================================================

Máximo 10 puntos.

A. Rentabilidad y Eficiencia (Máx 4 pts)

ROE (Return on Equity):
- +2 pts si > 15% y datos disponibles
- +1 pt si 10-15% y datos disponibles
- 0 pts si < 10% o N/A
- ETFs: 0 pts

Gross Margin (o Net Income Margin para Financieros):
- +2 pts si > 45% (GM) o > 15% (NIM para Financieros)
- +1 pt si 30-45% (GM) o 10-15% (NIM para Financieros)
- 0 pts si < 30% o N/A
- ETFs: 0 pts
- REITs: +2 pts si Gross Margin > 45% o AFFO Margin > 20%

B. Generación de Caja (Máx 4 pts)

FCF Margin (Sector Ajustado):
- +2 pts si cumple threshold y datos disponibles
- +1 pt si cerca del threshold (80-100%)
- 0 pts si no cumple o N/A

Thresholds por Sector:
- Tecnología/SaaS: > 15%
- Semiconductores: > 18%
- Comunicaciones: > 12%
- Financieros: usar Net Income Margin (> 10% = +2 pts)
- Industriales: > 8%
- Energía: > 10%
- Consumer Staples: > 8%
- Consumer Cíclico: > 6%
- Healthcare: > 12%
- REITs: usar AFFO Margin (> 20% = +2 pts)
- ETFs: 0 pts

FCF Margin Absoluto (o AFFO para REITs, o NIM para Financieros):
- +2 pts si > 20%
- +1 pt si 10-20%
- 0 pts si < 10% o N/A
- Financieros: +2 pts si NIM > 15%
- ETFs: 0 pts

C. Crecimiento Sostenible (Máx 2 pts)

Revenue Growth YoY:
- +1 pt si > 10% y datos disponibles
- +0.5 pt si 5-10% y datos disponibles
- 0 pts si < 5% o N/A
- ETFs: 0 pts

Beat Streak:
- +1 pt si ≥ 3 trimestres y datos disponibles
- 0 pts si < 3 o N/A
- ETFs: 0 pts

FASE 3: VALUATION SCORE (25% - Precio vs Valor Intrínseco)
================================================================================

Máximo 10 puntos.

A. PEG Ratio (Máx 4 pts)
- +4 pts si < 1.0 y datos disponibles (Infravalorado)
- +3 pts si 1.0 - 1.5 y datos disponibles (Razonable)
- +1 pt si 1.5 - 2.5 y datos disponibles (Algo caro)
- 0 pts si > 2.5, N/A, o no aplica (ej. REITs, ETFs, empresas sin crecimiento)
- REITs: usar Price/AFFO en lugar de PEG (si disponible): < 20x = +3 pts, 20-25x = +2 pts, > 25x = 0 pts
- Financieros: usar P/E vs histórico del sector en lugar de PEG

B. Yield y Retorno al Accionista (Máx 3 pts)

Dividend Yield:
- +1 pt si > 3% y datos disponibles
- +0.5 pt si 2-3% y datos disponibles
- 0 pts si < 2% o N/A

Payout Ratio:
- +1 pt si < 60% y datos disponibles (sostenible)
- 0 pts si > 60% o N/A

EPS Revision:
- +1 pt si "raising" y datos disponibles
- 0 pts si "stable", N/A, o no aplica
- -2 pts si "lowering" (penalización base)
- Penalización adicional -2 pts si "lowering" con magnitud > 15%

C. Valor Relativo por Sector (Máx 3 pts)

Forward PE vs Sector (basado en datos disponibles):
- +2 pts si significativamente bajo (PERCEPCIÓN DEL ANALISTA)
- +1 pt si moderadamente bajo
- 0 pts si en línea o alto o N/A

Price to FCF (o EV/EBITDA para cíclicos, o P/E histórico):
- +1 pt si < 20x y datos disponibles
- 0 pts si N/A
- Financieros: usar P/E vs histórico del sector
- REITs: usar Price/AFFO si disponible
- ETFs: 0 pts

================================================================================
FASE 4: TIMING SCORE (25% - Oportunidad de Entrada)
================================================================================

Máximo 10 puntos.

A. Soporte Técnico a Largo Plazo (Máx 3 pts)

Precio vs SMA 200:
- +2 pts si entre -10% y 0% (zona de soporte) y datos disponibles
- +1 pt si entre 0% y +5% y datos disponibles
- 0 pts si > +5% o < -10% o N/A

Cerca de 52W Low:
- +1 pt si < 15% del low y datos disponibles
- 0 pts si N/A o fuera de rango

B. RSI y Momento (Máx 4 pts)

RSI:
- +4 pts si RSI 30-45 y datos disponibles (OPORTUNIDAD IDEAL)
- +3 pts si RSI 46-55 y datos disponibles (Zona neutral)
- +1 pt si RSI 56-65 y datos disponibles (Algo caliente)
- 0 pts si RSI > 65 o N/A (Sobrecompra - EVITAR)
- ETFs: +1 pt adicional por ser instrumento diversificado

Value Trap Check (bonificaciones/penalizaciones):
- Si RSI < 30 Y (PEG > 3 O FCF < 0 O D/E > 200%): -2 pts (EVITAR)
- Si RSI < 30 Y fundamentales sólidos (ROE > 15%, FCF > 10%): +1 pt (OPORTUNIDAD DCA)
- Si datos insuficientes: 0 pts

C. Catalizadores y Sentimiento (Máx 3 pts)

Sentimiento Noticias:
- +1 pt si Bullish (score > 0.1) y datos disponibles
- 0 pts si Neutral (score -0.1 a 0.1) o N/A
- -1 pt si Bearish (score < -0.1)

Insider Signal:
- +1 pt si "bullish" o "mixed" y datos disponibles
- 0 pts si "neutral", "none", o N/A
- -1 pt si "bearish"

Volumen Ratio:
- +1 pt si > 1.0 y datos disponibles (interés creciente)
- 0 pts si 0.5-1.0 o N/A
- -1 pt si < 0.5 (falta de interés)

D. Earnings Catalyst (Máx 1 pt)
- +1 pt si 5-15 días y datos disponibles (potencial catalizador)
- 0 pts si fuera de esa ventana o N/A
